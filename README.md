# Prodplane

**Your path to production.**

Prodplane is a developer platform for turning application blueprints into complete AWS environments—from infrastructure provisioning to application delivery.

An environment brings together the infrastructure, application configuration, supporting services and release workflows needed to run an application stack. Reusable templates and environment definitions connect these pieces into one system.

## Platform scope

- Provision shared AWS and Kubernetes infrastructure with Terraform.
- Define application environments independently of their shared infrastructure.
- Configure application runtimes, secrets, storage and logging through reusable templates.
- Connect build pipelines and release events to application deployment and database migrations.
- Reuse the same platform definitions across environments and regions.

## Status

This repository is the starting point for Prodplane. The platform implementation has not yet been added.
